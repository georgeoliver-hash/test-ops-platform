=== C4100427 :: Validation — entitlement smartcard sets the ticket type  [section_id=886958]
Refs: FBD-100250
custom_devtypes: [5]
PREFACE: This test is to confirm that presenting an entitlement smartcard (Senior/Blind/War Pensioner/yLink/24+/Half-Fare/Dependants) sets the matching ticket type, validates per transaction, and cannot be basketed. Half-Fare sub-types: Partially Sighted, Learning Disability, No Driving Licence, PIPS, DLA.
PRECONDS: **GIVEN** the POS is signed on and selling a fare in NIR or Ulsterbus mode
**AND** an entitlement smartcard is available – example: a 60+ SmartPass selling a "60+ Single"
  STEP1 content: **WHEN** the operator presents an entitlement smartcard (e.g. Senior, Blind, War Pensioner, yLink, 24+, Half-Fare, Dependants)
  STEP1 expected: **THEN** the matching ticket type is set (e.g. "60+ Single", "Half Fare Single")
**AND** the fare must be validated per transaction
**AND** the fare cannot be added to a basket
**AND** the operator can still change the boarding station
**AND** the operator can still change the alighting station
  STEP2 content: **WHEN** the sale is on Rail
  STEP2 expected: **THEN** cross-border variants are selectable via the L4/R4 keys
  STEP3 content: **WHEN** a Half-Fare sub-type or DLA card is presented (Partially Sighted, Learning Disability, No Driving Licence, PIPS, DLA)
  STEP3 expected: **THEN** the matching ticket type is set
  STEP4 content: **WHEN** the CloudFare activity log is checked
  STEP4 expected: **THEN** the corresponding event is recorded in the Back Office System (CloudFare) activity log
  STEP5 content: **WHEN** the data is reviewed in MERIT
  STEP5 expected: **THEN** the transaction appears in MERIT
  STEP6 content: **WHEN** the smartcard record is reviewed in SmartTrack
  STEP6 expected: **THEN** the updated smartcard record appears in SmartTrack
EXPECTED: An entitlement smartcard sets its ticket type, requires per-transaction validation (no basketing), allows boarding/alighting change, and offers cross-border variants on Rail. NIR + Ulsterbus only.
Data variations: Concession — Senior / 60+ / ROI Senior / Blind / War Pensioner Smartpass categories.

[Automatable: Partial – Cross-check: CloudFare / MERIT / SmartTrack]
